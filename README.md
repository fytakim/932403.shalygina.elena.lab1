**Вариант:** 11 (Тема «Фотограф и визуальный сторителлер»)

## Описание работы

В проекте реализованы следующие элементы согласно техническому заданию:
* Использована правильная структура документа и семантические теги (`<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
* Добавлена секция «Навыки» с маркированным списком фотографических навыков (композиция, свет, ретушь).
* Добавлена секция «Проекты» с нумерованным списком серий снимков.
* Оформлена боковая панель (`<aside>`) с указанием любимого направления в фотографии.
* Вставлено изображение профиля с обязательными атрибутами (`src`, `alt`, `width`, `height`).
* Создана форма обратной связи, включающая поля ввода имени (`type="text"`), почты (`type="email"`), текстовую область для сообщения (`<textarea>`) и кнопку отправки. У всех полей прописаны атрибуты `name` и `placeholder`.
* Цветовая гамма страницы настроена в серо-синих тонах в соответствии с вариантом.

Код веб-страницы валиден и успешно проходит проверку через W3C Validator.
